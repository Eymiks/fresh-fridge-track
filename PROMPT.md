# Mission Codex — Développement Android

Lis `AGENTS.md` et `CLAUDE.md`, puis analyse le code Android réel dans `android/`.

## Objectif

Continuer le développement de l’application Android en se basant sur :

- l’état réel du code Android ;
- les fonctionnalités de la PWA de référence ;
- les issues GitHub labellisées `Android` ;
- les informations déjà présentes dans `AGENTS.md` et `CLAUDE.md`.

## Tâches

1. Lire `AGENTS.md` et `CLAUDE.md`.
2. Analyser `android/`.
3. Comparer l’application Android avec la PWA :
   - fonctionnalités manquantes ;
   - différences visuelles ;
   - comportements différents ;
   - bugs ou incohérences.
4. Vérifier uniquement les issues GitHub labellisées `Android`.
5. Produire un plan de développement priorisé.
6. Corriger en priorité les bugs ou erreurs bloquantes.
7. Avancer étape par étape.
8. À la fin de chaque étape :
   - mettre à jour `AGENTS.md` et `CLAUDE.md` ;
   - vérifier le diff ;
   - faire un commit Git avec un message clair.

## Contraintes

- Ne te fie pas uniquement aux fichiers mémoire : vérifie dans le code.
- N’invente aucune fonctionnalité.
- Signale les points incertains comme `à vérifier`.
- Ne modifie pas la PWA sauf nécessité stricte.
- Ne prends en compte que les issues GitHub labellisées `Android`.
- Travaille par petites étapes vérifiables.
- Ne pousse pas les commits sauf demande explicite.

## Résultat attendu

À la fin, indique :

- le plan suivi ;
- les bugs corrigés ;
- les fonctionnalités ajoutées ou améliorées ;
- les différences PWA / Android restantes ;
- les issues GitHub `Android` prises en compte ;
- les fichiers modifiés ;
- les commits créés.
